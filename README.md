# Mini Blog App

A simple blog app built with Node.js, Express, EJS, and MongoDB.

## Features

- View all posts
- View single post
- Add new posts with image
- Delete posts

## Skills

- Routing
- Dynamic URL parameters
- Templating (EJS)
- File upload with Multer
- MongoDB integration

## Installation

1. Clone the repository
   ```bash
   git clone https://github.com/yourusername/Mini-Blog-App.git
   ```
